# Development workspace

The activated canonical local checkout is represented in public documentation
as `<FORAKILO_WORKTREE>`. Exact machine-specific path mappings are retained in
private migration evidence rather than committed.

Create other worktrees only outside the canonical checkout. Never initialize a
parent repository around Forakilo and never place nested repositories inside
the worktree. External LEAN content belongs at `<EXTERNAL_LEAN_CHECKOUT>`.
